JWT & Swagger Verification Guide:
1. Open Swagger Docs at http://127.0.0.1:8000/docs
2. Execute POST /api/auth/login with the demo credentials to get your `access_token`.
3. Click the green "Authorize" button at the top right of the Swagger UI.
4. Paste the access token into the value field and click "Authorize".
5. Test the protected GET and POST endpoints (marked with lock icons):
   - [GET]  /api/auth/me                -> Verifies JWT authentication and retrieves user profile.
   - [POST] /api/auth/verify-token       -> Verifies token validity and inspects decoded claims.
   - [POST] /api/vector/search          -> PGVector semantic similarity search using cosine distance (<=>).
   - [GET]  /api/vector/similar/{id}    -> PGVector nearest neighbor transaction discovery.
   - [GET]  /api/vector/status          -> Diagnostics for PostgreSQL vector extension and HNSW index.
